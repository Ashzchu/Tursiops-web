HOW IT WORKS

One extension. A permanent record for every file.

01

You work as usual

Tell your agent — Copilot, IBM Bob, whatever you use — what to do. Nothing about your workflow changes.

02

Tursiops remembers

The prompt, the diff, the decision behind it, and the validation result get attached to that exact file.

03

It’s there next time

Restart VS Code, come back in a month — run one command and the full history is right there.

// ZERO TRUST POLICY

SECURITY

Built local-first, on purpose

01
No cloud account, no user database, no telemetry. Memory lives in your project folder.
02
Your API key stays in your OS keychain. Never in source, settings, or logs.
03
Secret files are filtered automatically. .env, .pem, id_rsa never reach any AI model.
04
Every AI change is a diff you approve. Nothing is written silently.

Command Palette & Extension Usage Guide for VS Code

Tursiops: Show File Memory

Ctrl+Alt+M / Cmd+Alt+M

Retrieves and displays the full architectural decision log, prompt history, diff changes, and type validation records associated with the currently open file in VS Code.

// COMMAND PALETTE SYNTAX
Press Ctrl+Shift+P -> Type "Tursiops: Show File Memory" -> Select active file
