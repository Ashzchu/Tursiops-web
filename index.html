Key Innovations

        
Why Developers Choose Tursiops

        

          Designed specifically to solve the "amnesia" problem of autonomous AI coding assistants.
        

      


      

        
        

          

            
          

          
File-Scoped Directives

          

            Attach rules directly to paths or globs. When an agent opens src/db/, it automatically receives your exact transaction patterns.
          

          

            .tursiops/directives.json
          

        


        

          

            
          

          
Cross-Session Continuity

          

            Clear your context window or swap between Claude Code, Cursor, and Copilot without re-prompting rules. Your architectural constraints survive every wipe.
          

          

            Zero Context Eviction
          

        


        

          

            
          

          
100% Offline & Git-Native

          

            No remote telemetry or forced cloud lock-in. Your memory lives in plain text and SQLite inside your repo. Commits and branches alongside your code.
          

          

            Air-gapped Ready
          

        


        

          

            
          

          
Regression Prevention

          

            Linter-style AST guards detect when an AI model attempts to delete an error handler, revert a schema fix, or ignore established conventions.
          

          

            Deterministic Verification

export async function createSessionToken(user: UserSession): Promise<string> {
  const secretKey = await importPrivateKey(process.env.AUTH_PRIVATE_KEY);
  
  return await new SignJWT({
    sub: user.id,

Under the Hood

        
How Tursiops Operates

        

          A lightweight local daemon and CLI that hooks into your editor's LSP and agent MCP server.
        

      


      

        

          
01

          

            
Repository Initialization

            
Runs tursiops init to generate .tursiops/. Indexes project structure, AST symbols, and existing developer guidelines.

          

        

        

          
02

          

            
Continuous Session Observation

            
Monitors prompts and generated diffs. Distills decisions (e.g. "We switched from fetch to axios with custom retry") into structured memory nodes.

          

        

        

          
03

          

            
Context-Aware Injection

            
When any AI agent opens or edits a file, Tursiops matches glob patterns and injects pinned directives straight into the agent's MCP context.

          

        

        

          
04

          

            
Conflict-Free Git Versioning

            
Memories are saved as clean JSON-Lines. When committing or creating pull requests, team memories merge automatically without merge conflicts.
