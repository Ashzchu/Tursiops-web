USER MANUAL

Set up once — then it runs alongside your normal coding, no habit changes required.

Getting Started

1
Install Tursiops from the VS Code Marketplace — it appears in your side panel.
2
Sign in or sign up from the panel → you're redirected to the browser to authenticate → you're sent straight back to VS Code, signed in.
3
Paste in your own Gemini API key when prompted. This key powers every refine, summary, and navigation call.

Your daily flow — nothing changes

Keep prompting your agent exactly as before. Tursiops runs quietly underneath: saving each prompt, refining it with Gemini, and feeding that context back to your agent before its next build. You don't have to do anything extra.

The one habit that matters

Just keep prompting your agent normally — Tursiops does the saving and refining on its own. The only manual step is the one-time sign-in and API key setup; everything after that is automatic.
